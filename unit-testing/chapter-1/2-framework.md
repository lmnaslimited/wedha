# Lesson 2: Unit Testing Frameworks – Overview

## Learning Objectives
By the end of this lesson, learners will be able to:
- Understand what a Unit Testing Framework is
- Identify popular testing frameworks
- Explain responsibilities of a framework
- Understand test runners and reports
- Choose the right framework

---

## What is a Unit Testing Framework?

A Unit Testing Framework is a **tool that helps developers write, run, and manage tests easily**.

It provides:
- Test structure
- Assertions
- Test execution
- Reporting

---

## Popular Unit Testing Frameworks

### JavaScript
- **Jest** – All-in-one testing framework
- **Mocha** – Flexible test framework

### Python
- **pytest** – Simple and powerful testing framework

---

## Framework Responsibilities

A testing framework is responsible for:
- Discovering test files
- Running tests automatically
- Providing assertion methods
- Reporting test results
- Handling test setup and teardown

---

## Test Runner and Test Reports

### Test Runner
- Executes test cases
- Tracks passed and failed tests

### Test Reports
- Show test results
- Display errors and failures
- Provide execution time
---
## Choosing the Right Framework

Consider:
- Programming language
- Project size
- Community support
- Ease of setup
- Built-in features

**Why Jest?**
- Zero configuration
- Built-in assertions
- Fast execution
- Great for beginners

---

## Summary

Testing frameworks simplify testing by automating execution and reporting, making unit testing efficient and reliable.
